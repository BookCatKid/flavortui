# flavourtui (SHIM PACKAGE)

This is a shim package for [`flavortui`](https://pypi.org/project/flavortui/). PLEASE USE `flavortui` INSTEAD OF THIS PACKAGE!

## Installation

_You can technically use this one, it will install `flavortui` as a dependency and run it when you run `flavourtui`, but it's recommended to just install `flavortui` directly._

```bash
pip install flavourtui
```

## Usage

```bash
flavourtui
```
